Privacy and limitations

Read this before using the demonstration.

◈
Educational use only

The nutrition values are sample estimates. They are not a diagnosis, treatment plan or personalized dietary recommendation.

♧
No account security

Login, access control and multi-user permissions are not implemented. Do not put real sensitive health information into this application.

⚙
Testing-friendly architecture

The application exposes service-layer logic and local endpoints for unit, functional, accessibility, performance and baseline security testing.
